# CSV 在线预览工具

一个纯前端的单文件 CSV 工具，双击 `index.html` 即可使用，无需安装、无需后端、无任何外部依赖。

## 功能特性

- 📂 **多种导入方式**：支持点击选择文件、拖拽上传、粘贴 CSV/TSV 文本，或从 URL 导入。
- 🔍 **分隔符自动检测**：自动识别逗号、制表符、分号分隔，也支持手动切换。
- 📝 **首行表头开关**：默认将第一行作为表头，关闭时自动生成「列1、列2…」。
- 📊 **表格预览**：粘性表头、斑马纹、行号列、单元格悬停高亮，空单元格以 ∅ 标识。
- 🔄 **三种视图**：「预览」（表格）/「源码」（原始 CSV 文本，带行号与分隔符、引号语法着色）/「对比」（源码与表格左右分屏，窄屏自动堆叠），并记忆上次选择。
- 🔼🔽 **排序**：点击表头实现升序 / 降序 / 还原三态切换，数字列自动按数值排序。
- 🔎 **实时搜索过滤**：输入即过滤所有列，显示「共 N 行 · 匹配 M 行」。
- 📋 **复制与导出**：
  - 悬停单元格一键复制单格内容；
  - 一键复制当前过滤后的 CSV 文本；
  - 下载当前数据为 `.csv`；
  - 导出为按表头映射的对象数组 `.json`。
- 📈 **实时统计**：文件大小、行数 × 列数、有效状态。
- ⚠️ **错误处理**：解析失败或列数严重不一致时，可编辑原文重试。
- 🚀 **大文件保护**：超过 5000 行时仅渲染前 2000 行，复制/下载仍使用全量数据。
- 🎨 深浅色主题切换，自适应移动端。

## 使用方式

直接用浏览器打开 `index.html` 即可：

```bash
open index.html        # macOS
# 或拖入浏览器
```

点击「示例」可快速体验效果。

## 技术说明

- 单一 HTML 文件，原生 HTML / CSS / JavaScript，零依赖、零构建步骤。
- CSV 解析器手写实现，兼容 RFC 4180：支持引号包裹字段、引号内逗号与换行、`""` 转义。
- 所有解析与渲染均在浏览器本地完成，不上传任何数据。
